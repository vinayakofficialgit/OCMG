# Windows only, and only when torch fails to import with WinError 126.
# torch_cpu.dll imports vcruntime140_threads.dll, which ships with the Visual
# C++ 2015-2022 redistributable from about 14.30; a machine carrying the
# VS2019 runtime (14.28) has vcruntime140.dll and vcruntime140_1.dll but not
# that one. This wheel carries the same Microsoft-signed DLL, so it repairs
# the import without administrator rights.
#   python scripts/fix_torch_dll.py
# does the whole thing: downloads it, extracts the single DLL into
# torch/lib, and re-checks the import.
